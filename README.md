# eslint-prettier-starter

This project is a **starter template** for Node.js developers to quickly integrate **ESLint** and **Prettier** into their workflow. 

It demonstrates:
- How to configure ESLint for linting and code quality.
- How to configure Prettier for consistent formatting.
- How to use ESLint and Prettier together without conflicts.
- Scripts for linting, fixing, and formatting your code.

Perfect for beginners or teams who want **clean and consistent code** in Node.js projects.
